# Wild_Blueberry_Yield_Prediction

## Project Overview

The objective of this project is to assist farmers and agricultural planners in accurately predicting wild blueberry yields using machine learning techniques. Several regression models are developed, trained, and evaluated to identify the most effective approach for yield prediction.

## Models Implemented

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- XGBoost Regressor

## Dataset

**File:** `WildBlueberryPollinationSimulationData.csv`

The dataset includes various factors that influence blueberry production, such as:

- Pollinator populations:
  - Honeybee
  - Bumblebee
  - Andrena
  - Osmia
- Fruit characteristics:
  - Fruit Set
  - Fruit Mass
  - Seeds

**Target Variable:** `Yield`
